# うおやんクッキングメモ

うおやんのメニューの作り方（時間・手順・盛り付け）を、スマホで見て、**ログインなしで誰でも追加・修正できる**マニュアル。LINEでリンクを送って使う。

## 使い方

- ふだんは閲覧専用。カードをタップで開く。上の検索とタブで探せる
- 画面下の「✏ 編集する」→ 最初だけ名前を入れる（履歴に残す用）→ 編集モード
  - カードを開くと「編集」「履歴」「ゴミ箱へ」
  - カテゴリごとに「＋ ○○にメニューを追加」、いちばん下に「新しいカテゴリでメニューを追加」
  - カテゴリの共通メモ（ピザの焼き方など）も編集できる
  - 時間タグは1行に1つ。「チン」「焼く」「揚げる」で始めると色がつく
- 消しても本当には消えない。いちばん下の「ゴミ箱」から戻せる
- 画面下の「変更履歴」で、誰が・いつ・何を変えたか（消した行・足した行）を誰でも見られる
- カードの「履歴」から、そのメニューの前の状態に戻せる（編集モード）
- 2人が同時に同じメニューを編集したら、あとから保存した人に「先に変更されたよ」と出て、勝手に上書きしない

## 技術構成（ふたりの予定と同じ）

| 層 | 採用 |
| --- | --- |
| 画面 | 素の HTML/CSS/JS（ビルドなし）`public/` |
| API | Vercel Serverless Functions `api/*.js` |
| DB | Neon Postgres |

- `api/state.js`（GET）: カテゴリ・メニュー・ゴミ箱を全部読む
- `api/menu.js`（POST）: `action` = `create` / `update` / `delete`（ゴミ箱へ）/ `restore` / `revert`（履歴から戻す）
- `api/history.js`（GET）: パラメータなし＝全体の最近の変更100件。`?target=menu&id=…` / `?target=category&id=カテゴリ名` で1つ分
- `api/category.js`（POST）: 共通メモの `update` / `revert`

テーブルは `db/schema.sql`。**API が最初に動いたときに自動で作られ、`db/seed.json` の初期メニューが1回だけ入る**（`npm run migrate` は不要）。
どの変更も「メニューを変える」と「履歴を1行足す」を1つのSQL文で行うので、片方だけ成功することはない。

## デプロイ

1. Neon でプロジェクトを作り、接続文字列（pooled）をコピー
2. Vercel で このリポジトリを Import（Framework: Other。`vercel.json` が出力先 `public` を設定済み）
3. 環境変数 `DATABASE_URL` に接続文字列を登録して Deploy

## ローカルで動かす・テスト

```bash
npm install
npm run dev     # http://localhost:3000 （DATABASE_URL が無ければ組み込みDB .pglite/ を使う）
npm test        # 別の画面で。本番DBに向けて実行しないこと
```
